## 🚀 Project Objective

Retail businesses often struggle to balance inventory levels while meeting customer demand. Overstocking increases holding costs, while understocking leads to lost sales.

The objective of this project is to:

- Analyze historical retail sales data.
- Identify high-value products using ABC (Pareto) Analysis.
- Forecast future demand using Machine Learning.
- Build an interactive Power BI dashboard that supports strategic assortment planning and inventory optimization.

---

## 📊 Dataset

This project uses the **UCI Online Retail Dataset**, containing approximately **392,000 cleaned retail transactions** from a UK-based online retailer.

The dataset includes:

- Customer transactions
- Product information
- Quantity sold
- Sales revenue
- Invoice dates
- Country information

---

## ⚙️ Methodology

The project follows a complete Business Analytics workflow:

### 1. Data Cleaning
- Removed missing values
- Eliminated duplicate transactions
- Filtered cancelled orders
- Processed outliers

### 2. Exploratory Data Analysis (EDA)
- Sales trends
- Customer purchasing behavior
- Product performance
- Revenue analysis

### 3. Feature Engineering
- Sales metrics
- Product performance indicators
- Time-based features

### 4. ABC Analysis
Products were classified into:

- **A:** High-value products
- **B:** Medium-value products
- **C:** Low-value products

using the Pareto Principle (80/20 Rule).

### 5. Machine Learning

An **XGBoost Regression Model** was developed to forecast product demand and support inventory planning.

### 6. Business Intelligence

Interactive dashboards were created using **Power BI** to communicate insights to decision-makers.
